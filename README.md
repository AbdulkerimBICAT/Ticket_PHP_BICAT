# Ticket BICAT

Projet PHP simple pour le ticket.

Etapes du sujet :
1. Créer l'environnement de travail
2. Mettre en place Git
3. Créer le formulaire
4. Traiter la sélection
5. Importer la base de données
6. Traitement du bon code
7. Traitement du zéro
8. Publier sur GitHub

Pour pousser sur GitHub :
1. Créer un dépôt public
2. git remote add origin <url-du-depot>
3. git push -u origin master
